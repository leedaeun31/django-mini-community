# django-mini-community
# 📌 서비스 개요

저희 서비스는 **웹 기반 소통 플랫폼**으로, 사용자가 자신만의 **방(Room)**을 만들어 커뮤니티를 형성하고 게시글과 댓글을 통해 의견을 나눌 수 있는 서비스입니다.

---

## 🛡️ 서비스 운영 원칙
- 건전한 커뮤니티 환경을 조성하기 위해 이용자 콘텐츠를 **엄격히 관리**합니다.
- 서비스 이용 약관과 커뮤니티 가이드라인을 통해 **모든 이용자에게 안전한 환경**을 제공하는 것을 최우선 목표로 합니다.

---

## 🚨 신고 및 커뮤니티 가이드라인

모든 이용자가 안심하고 서비스를 이용할 수 있도록, 아래와 같은 커뮤니티 가이드라인을 준수해 주시기 바랍니다.

### 커뮤니티 가이드라인
저희는 다음과 같은 콘텐츠의 게시를 **엄격히 금지**합니다.
- **욕설 및 모욕적인 언어**: 타인에게 불쾌감을 주거나 인신공격적인 내용
- **불법 정보**: 불법적인 활동을 조장하거나 관련 정보를 공유하는 내용
- **음란물 및 선정적인 콘텐츠**: 과도하게 선정적이거나 성적인 내용
- **차별 및 혐오 발언**: 인종, 성별, 종교, 장애 등에 대한 차별이나 혐오를 조장하는 내용
- **스팸 및 광고성 콘텐츠**: 특정 상품이나 서비스를 홍보하기 위한 목적의 도배성 게시물

### 신고 절차 안내
부적절한 콘텐츠를 발견했을 경우, 다음과 같은 방법으로 신고할 수 있습니다.
1. **게시물/댓글 신고**: 각 콘텐츠 우측의 **'신고하기' 버튼**을 통해 즉시 신고할 수 있습니다.
2. **피해 사례 신고**: 직접적인 피해를 입으신 경우, **고객센터 이메일**을 통해 상세 내용을 접수해 주시면 신속히 처리하겠습니다.

### 제재 조치
신고된 콘텐츠는 **24시간 이내**에 운영자가 직접 검토하며, 위반 정도에 따라 다음과 같은 조치가 이루어집니다.
- **1단계**: 문제 콘텐츠 즉시 삭제 및 작성자에게 경고
- **2단계**: 서비스 일정 기간 **계정 정지**
- **3단계**: 반복적인 위반 시 **계정 영구 차단**

---

## 🛠️ 관리 체계
- 운영자는 게시글·댓글 전체를 조회하고 삭제할 수 있는 **관리자 페이지**를 보유하고 있습니다.
- 모든 신고 처리 내역은 기록되며, 재발 방지를 위한 데이터로 활용됩니다.
- 필요시 수사 기관과 협조할 수 있는 절차를 마련해두고 있습니다.

## 📌 주요 기능

### 🏠 메인 페이지
- 로그인 및 회원가입 기능
- 사용자가 참여한 방 목록 확인
- 초대 링크를 통한 방 등록

### ➕ 방 생성 기능
- 방 이름과 PIN(비밀번호) 입력 후 방 생성 가능
- 방 생성자는 자동으로 **방장 권한** 부여
- 방 삭제 및 PIN 변경 가능

### 📄 방 상세 페이지
- 게시글 업로드 (제목, 텍스트, 여러 장의 이미지 업로드)
- 게시글 목록 조회 (작성자, 작성 시간, 댓글 수 표시)
- 댓글 작성·수정·삭제 기능
- 방 초대 URL 확인 및 복사

### 👤 마이페이지
- 닉네임 변경
- 프로필 이미지 업로드·변경

### 🔑 소셜 로그인
- 네이버 계정을 통한 로그인 지원

---

## 📂 업종 및 콘텐츠 형태
- **업종**: 커뮤니티 서비스 / SNS 플랫폼
- **콘텐츠 형태**:
  - 텍스트 기반 게시글 및 댓글
  - 이미지 업로드 및 공유
  - 사용자 프로필 관리 & 소셜 로그인

## 🌐 서비스 URL
- **개발 환경**: `http://localhost:8000`
- **운영 환경(예정)**: `https://<도메인>`
  - 운영 환경에서는 누구나 접근 가능
  - 위에서 설명한 커뮤니티 기능 중심으로 제공
