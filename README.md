# 📌 서비스 개요

저희 서비스는 **웹 기반 소통 플랫폼**으로, 사용자가 자신만의 **방(Room)**을 만들어 커뮤니티를 형성하고  
게시글과 댓글을 통해 의견을 나눌 수 있는 서비스입니다.

---

## 🛡 서비스 운영 원칙
- 건전한 커뮤니티 환경을 조성하기 위해 이용자 콘텐츠를 **엄격히 관리**합니다.
- 서비스 이용 약관과 커뮤니티 가이드라인을 통해 **모든 이용자에게 안전한 환경**을 제공합니다.

---

## 📑 이용자 콘텐츠 관리 정책
2. 운영자가 주기적으로 게시글과 댓글 모니터링
3. 이용자는 **신고하기 버튼**으로 부적절한 콘텐츠 신고 가능
4. 신고된 게시물은 **24시간 이내** 운영자가 검토 후 삭제 또는 작성자 제재

---
## 📑 이용자 콘텐츠 관리 정책
1. **키워드 필터링 시스템**으로 욕설, 음란 단어 포함 게시글 자동 차단
2. 운영자가 주기적으로 게시글과 댓글 모니터링
3. 이용자는 **신고하기 버튼**으로 부적절한 콘텐츠 신고 가능
4. 신고된 게시물은 **24시간 이내** 운영자가 검토 후 삭제 또는 작성자 제재

---

## 🛠 관리 체계
- 운영자는 게시글·댓글 전체를 조회/삭제할 수 있는 **관리자 페이지** 보유
- 신고 처리 내역 기록 및 재발 방지를 위한 제재 시행
- 반복 위반 이용자는 일정 기간 **계정 정지** 또는 **영구 차단**

---

## 🧾 이용자 보호
- 피해 사례 발생 시 **이메일/고객센터**를 통한 신고 접수 및 신속 처리
- 필요 시 수사 기관과 협조할 수 있는 절차 마련

---

## 📌 주요 기능

### 🏠 메인 페이지
- 로그인 및 회원가입 기능
- 사용자가 참여한 방 목록 확인
- 초대 링크를 통한 방 등록

### ➕ 방 생성 기능
- 방 이름과 PIN(비밀번호) 입력 후 방 생성 가능
- 방 생성자는 자동으로 **방장 권한** 부여
- 방 삭제 및 PIN 변경 가능

### 📄 방 상세 페이지
- 게시글 업로드 (제목, 텍스트, 여러 장의 이미지 업로드)
- 게시글 목록 조회 (작성자, 작성 시간, 댓글 수 표시)
- 댓글 작성·수정·삭제 기능
- 방 초대 URL 확인 및 복사

### 👤 마이페이지
- 닉네임 변경
- 프로필 이미지 업로드·변경

### 🔑 소셜 로그인
- 네이버 계정을 통한 로그인 지원

---

## 📂 업종 및 콘텐츠 형태
- **업종**: 커뮤니티 서비스 / SNS 플랫폼
- **콘텐츠 형태**:
  - 텍스트 기반 게시글 및 댓글
  - 이미지 업로드 및 공유
  - 사용자 프로필 관리 & 소셜 로그인

---

## 🌐 서비스 URL
- **개발 환경**: `http://localhost:8000`
- **운영 환경(예정)**: `https://<도메인>`
  - 운영 환경에서는 누구나 접근 가능
  - 위에서 설명한 커뮤니티 기능 중심으로 제공
